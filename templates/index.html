SECURITY CAPABILITIES

Multi-Layer URL Analysis

Each layer examines a different part of the submitted target before the findings are combined.

URL Analysis

HTTPS, IP usage, suspicious keywords, length, subdomains, ports, query parameters, URL shorteners and unusual symbols.

Domain Intelligence

Domain age, TLD reputation, Punycode, Unicode homographs, typosquatting, entropy and domain similarity.

Network & SSL

WHOIS, DNS records and SSL certificate information provide registration and infrastructure context.

Webpage Behaviour

Redirects, forms, JavaScript, page content, favicons and other browser-facing security indicators.

Server Security

Security headers, cookies, CORS, HTTP methods, robots.txt, sitemap and sensitive-file exposure checks.

Threat Intelligence

VirusTotal reputation information is combined with independent analyzer evidence to strengthen the assessment.

Content & Service Notices

Adult or explicit content and gambling/betting services receive a red warning before the result. Financial and cryptocurrency services receive an amber caution. These notices remain separate from the cybersecurity risk score.
