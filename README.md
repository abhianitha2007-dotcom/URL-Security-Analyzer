# URL Security Analyzer

A web-based cybersecurity tool that analyzes URLs for common phishing indicators and calculates a security risk score.

## Features

- HTTPS Detection
- IP Address Detection
- URL Length Analysis
- Suspicious Keyword Detection
- Subdomain Analysis
- Risk Score Calculation
- Scan History (Coming Soon)
- WHOIS Lookup (Coming Soon)
